# Аудиодорожка: что автор сказал словами

Видео `vsdc-sr 2026-10-22 23-13-29_compross.mp4` — 6:49, звук AAC 44.1 кГц. Кадры показывают
интерфейс, но половина требований звучит только в речи: что убрать, что обязательно оставить и
как это должно вести себя на Windows 11.

**Как получен транскрипт.** Офлайн, без облака и без Hugging Face (домен недоступен в песочнице):
аудио декодировано в 16 кГц моно, распознано `faster-whisper` (CTranslate2 int8, модель Whisper
**small**) на CPU — 409 секунд звука за 156 секунд. Модель взята из npm-пакета
`@skillninja/shortmovie-telop-model-p0…p3` (MIT, 4 части, sha256 проверена при склейке).

## Чем распознавали (воспроизводимо)

```bash
python -m venv /tmp/venv && /tmp/venv/bin/pip install faster-whisper av
# модель Whisper small в CTranslate2 int8 (npm, MIT):
npm pack @skillninja/shortmovie-telop-model-p0   # + p1, p2, p3
cat */package/model.bin.part* > model.bin        # sha256 ca732cb1…404ce73
ffmpeg -i video.mp4 -ac 1 -ar 16000 -f s16le audio.raw
```
