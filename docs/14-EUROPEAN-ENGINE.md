# Европейский движок: Parakeet TDT 0.6B v3 вместо Whisper для английского и других европейских языков

Версия 1.18.0. Документ отвечает на три вопроса: зачем третий движок, как он
устроен у нас и что именно проверено, а что ещё нет.

---

## 1. Зачем

После 1.11.0 у нас два движка: русская модель для русского языка (быстрая,
ставит знаки сама) и whisper для всего остального. Для английского это значило
компромисс: «Быстро» — заметно быстрее речи, но с ошибками; «Максимум» — точнее,
но человек ждёт. Плюс whisper не ставит знаки препинания на английском так, как
это делает современная модель, обученная на диктовку.

**Parakeet TDT 0.6B v3** (NVIDIA, CC BY 4.0, 600 млн параметров) — многоязычная
модель на 25 европейских языков. По карточке модели: пунктуация и заглавные
ставит сама, язык определяет сама, средний WER по FLEURS ≈ **11,97 %** (русский —
5,51 %, английский — 4,85 %), и по замерам независимых обзоров она в разы быстрее
whisper при сопоставимом качестве. На Open ASR Leaderboard английский у Parakeet
V2 — 6,05 % WER против 7,44 % у Whisper Large V3.

Русский мы ей не отдаём: для русского есть отдельная модель, обученная только на
русском, и она в 2,8 раза меньше (226 МБ против ≈640 МБ).

## 2. Что происходит при диктовке

```
микрофон → 16 кГц → обрезка тишины → выбор движка (electron/sttEngine.cjs)
   ├─ русский + русская модель       → GigaAM v3
   ├─ английский, немецкий, французский, испанский, украинский
   │      + модель европейских языков → Parakeet TDT v3
   │           признаки (nemo128) → энкодер → жадный TDT → словарь → текст
   └─ иначе (китайский, японский, турецкий, казахский, нет модели)
          → whisper.cpp, как раньше
```

Решение принимает не человек, а `electron/sttEngine.cjs`:

| Язык | Модель европейских языков | Что будет |
|---|---|---|
| русский | не важно | русская модель (или whisper, если её нет) |
| en, de, fr, es, uk | скачана | европейская модель |
| en, de, fr, es, uk | нет или сломана | whisper, причина — в журнал |
| zh, ja, tr, kk | не важно | whisper: эта модель такие языки не знает |

Настроек не прибавилось (их по-прежнему 39): выбор движка — это язык, а не вкус.
Запись короче секунды уходит в whisper: модели нужно окно признаков, а на «да» и
«нет» разницы не видно.

## 3. Как устроено

| Файл | Что делает |
|---|---|
| `electron/sttEngine.cjs` | политика выбора движка (чистая функция, покрыта тестами) |
| `electron/parakeet.cjs` | скачивание и проверка файлов, сессии ONNX Runtime, TDT-декодирование |
| `electron/chunking.cjs` | разрез длинной записи в самом тихом месте около середины, склейка кусков (общий с русской моделью) |
| `electron/modelDownload.cjs` | скачивание с проверкой размера и SHA-256 (общий для всех моделей) |
| `scripts/check-parakeet.mjs` | проверка на настоящем звуке без интерфейса |
| `scripts/lib/engine-cli.mjs` | общая обвязка проверок: WAV, пересчёт частоты, прогресс |

Порядок шагов сверен с `onnx-asr` — тем самым экспортом, на котором модель и
собрана (`istupakov/parakeet-tdt-0.6b-v3-onnx`, коммит
`8f23f0c03c8761650bdb5b40aaf3e40d2c15f1ce`):

1. **Признаки.** Граф `nemo128.onnx` (140 КБ) превращает звук 16 кГц в 128
   мел-полос с нормализацией. Считать это в JavaScript — верный способ разойтись с
   эталоном в третьем знаке и получить «почти правильный» текст, поэтому граф
   скачивается вместе с моделью.
2. **Энкодер.** FastConformer int8 (622 МБ) сжимает время в 8 раз и выдаёт вектор
   на кадр.
3. **Декодирование TDT.** Декодер-джойнт на каждый кадр выдаёт не только токен, но
   и «сколько кадров пропустить» (0–4). Именно поэтому модель считает в разы
   быстрее речи: на тишине она перескакивает кадры, а не идёт по ним по одному.
4. **Словарь.** 8193 кусочка SentencePiece, `▁` — пробел, `<blk>` — пустой токен.

## 4. Размер и скорость

| Что | Сколько |
|---|---|
| установщик | не растёт (Parakeet — та же сборка ONNX Runtime, что и для русского) |
| модель (скачивается один раз) | ≈ 640 МБ (энкодер 622 МБ + декодер-джойнт 18 МБ + два маленьких файла) |
| оперативная память на время диктовки | ≈ 1,2–1,5 ГБ |
| скорость (по замерам авторов экспорта и обзоров) | от 15 до 26 раз быстрее реального времени на процессоре |

640 МБ — это отдельное решение человека, а не сюрприз: перед скачиванием размер
написан на карточке, а скачивание можно отменить.

## 5. Что проверено, а что нет

**Проверено (`npm run test:main`, 109 проверок, из них три новых):**

- словарь: разбор файла, `▁` → пробел, служебные токены не попадают в текст,
  битые строки пропускаются;
- **TDT-декодирование целиком** — на подставных сетях с той же формой входов и
  выходов, что у настоящих: пропуск кадров по длительности (и проверка, что
  пропущенные кадры действительно не считаются), предел токенов на кадр, отказ на
  чужой частоте дискретизации;
- выбор движка: восемь сочетаний языка, модели и длины записи, включая
  китайский и японский (остаются на whisper) и отсутствие модели;
- скачивание с проверкой размера и хеша — общий код с русской моделью, проверен
  на локальном сервере, включая отказ на повреждённом файле;
- кнопка отмены передаётся и русской, и европейской модели. Начиная с 1.39.0
  она прерывает сетевой поток, не дожидаясь конца файла; проверка использует
  локальный сервер. Готовые файлы остаются, начатый файл удаляется и при
  повторе скачивается заново. Проверка наличия уже лежащих файлов по-прежнему
  сравнивает размер, а не перечитывает весь хеш при каждом открытии настроек.

**Не проверено здесь:** распознавание настоящей речи настоящими весами. В
песочнице, где собиралась версия, нет доступа к Hugging Face, поэтому скачать
640 МБ и прогнать запись было невозможно. Это надо сделать на рабочей машине:

```bash
node scripts/check-parakeet.mjs --download          # один раз, ≈640 МБ
node scripts/check-parakeet.mjs записи/english.wav  # текст, время, скорость
node scripts/check-parakeet.mjs --wav-dir записи    # и сравнить с whisper на тех же файлах
```

Скрипт печатает текст, секунды счёта и во сколько раз быстрее реального времени.
Если текст окажется хуже, чем у whisper, — движок выключается одной строкой в
политике (`electron/sttEngine.cjs`), и всё возвращается к прежнему поведению.
