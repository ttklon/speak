## 3. Функциональность, считанная с экрана

1. **Глобальная диктовка в любое поле** — основная фича. Работает через вставку текста по хоткею (видимо Ctrl+?).
2. **Счётчики слов и WPM** — 144 слова, 9.0 сек — средняя скорость.
3. **История диктовок (Недавние)** — сохраняет транскрипты с временем, можно кликнуть и скопировать.
4. **Словарь** — пользователь добавляет сложные слова («аренда»), чтобы улучшить распознавание. Поле «Слово» + «Произношение».
5. **Горячие клавиши** — полностью настраиваемые: Диктовка, Режим замены, Диктовка с ручной правкой, Снова запись и т.д. Можно добавить свою инструкцию с AI-промптом.
6. **AI-инструкции** — «Сделать формально», «Перевести на английский», «Понизить термины» — это пресеты промптов, которые прогоняют текст через LLM/локальную модель.
7. **Заметки о встречах** — запись с микрофона/системы, транскрибация и саммаризация. Интеграция с календарём, Import File.
8. **Живой перевод** — выбор источника (Микрофон + Система), выбор языка (Английский по умолчанию), кнопка «Начать сессию», история сессий.
9. **Буфер обмена** — мониторит всё что копируешь (текст, файлы, ссылки, картинки), сохраняет историю до 10 000 элементов, показывает сеткой/списком, поиск по содержимому, превью.
10. **Настройки хранения** — сколько дней хранить голосовые диктовки (36 дней), сколько места занимает (25,2 МБ), автоудаление.
11. **Мобильное приложение** — QR для установки на iOS/Android, синхронизация?
12. **Тариф Free** — 800 слов (8 / 800 использовано на момент записи), кнопка «Обновить» (апгрейд).
13. **Поиск по всем данным** — верхнее поле ищет по транскриптам/буферу.
14. **Пригласить друзей** — реферальная программа.

## 5. Выводы для клонирования

- Приложение — **десктопный voice-assistant для Windows 11**, написан скорее всего на Electron/Tauri или WPF (тёмная тема, нативные тоглы, глобальные хоткеи).
- Клон в **.NET (WPF + Win32)** полностью покрывает все фичи без облака: STT через `Whisper.NET` (ggml tiny/small), VAD через Silero, AI-полировка через локальный `Phi-3 / Qwen2.5 0.5B` via ONNX или опционально Ollama, буфер обмена через `ClipboardHook`, хранение в `SQLite`.
- UI — одно окно 820×540, сайдбар 7 пунктов + настройки, модалки, тёмная палитра, pill-кнопки, зелёные тогглы.

Все скриншоты и таймлайн сохранены в этом репозитории для сверки пиксель-в-пиксель.
