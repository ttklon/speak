[CI 44930549078](https://github.com/ttklon/speak/actions/runs/44930549078)
для `f578877`: `check`, `onnx-live`, `windows-full-ui` success, Windows unit
942/942 и полный UI 440/440; `package` failure, `release` skipped. До GUI
установщика этот прогон не дошёл: тест отдельного окна получил Windows sharing

повторяет только чтение при sharing/lock violation, не повторяя уже выполненные
действия; добавлен Windows-сценарий с искусственно удерживаемой блокировкой.


[CI 44971673328](https://github.com/ttklon/speak/actions/runs/44971673328)

## Следующие действия

1. Продолжить аудит смысловых потерь на командах, оговорках, оформлении и
   распознавании речи; ни текущие unit-, ни моковые UI-тесты не доказывают
   точность на живом микрофоне.
2. Продолжить работу над восстановлением профиля и безопасной конфигурацией
   необязательного сервера журналов с учётом совместимости desktop-клиента.
3. Расширить проверку обновления на другие реальные варианты старых профилей и
   установленной Windows, отдельно от проверки с изолированным тестовым профилем.
