## Стадия 1 — .NET и инструменты (30 минут, бесплатно)

1.1. Установить .NET SDK 8.0 LTS (x64): https://dot.net — выбрать `dotnet-sdk-8.0.xxx-win-x64.exe` → Next-Next. Альтернатива winget: `winget install Microsoft.DotNet.SDK.8`  
1.2. Проверить: `dotnet --version` → `8.0.xxx`, `dotnet --list-sdks`  
1.3. Установить Git for Windows + GitHub CLI: `winget install Git.Git GitHub.cli`  
1.4. Установить Visual Studio 2022 Community (бесплатно) или VS Code: `winget install Microsoft.VisualStudio.2022.Community` (выбрать workload «Разработка классических приложений .NET») или `winget install Microsoft.VisualStudioCode`  
1.5. Установить Windows App SDK / WPF — входит в SDK, ничего дополнительно. Проверить: `dotnet new wpf -n TestApp && dotnet build TestApp`  
1.6. Установить SQLite (встроен), ffmpeg не нужен для MVP (используем NAudio).  
1.7. Клонировать репо: `git clone https://github.com/ttklon/speak.git C:\dev\speak` → `cd C:\dev\speak` → `git checkout arena/c0441a45-speak`  
1.8. Проверить сборку пустого решения: `dotnet new sln -n Speak && dotnet sln add ...` — убедись что `msbuild` проходит.

**Критерий:** `dotnet build` зелёный, приложение WPF открывается.

## Стадия 2 — Архитектура решения (бесплатно, локально)

2.1. Структура солюшена (создаём один раз):
```
Speak.sln
src/
  Speak.App/          — WPF, MVVM, MainWindow 820×540
  Speak.Core/         — домен, модели, SQLite, сервисы
  Speak.Audio/        — запись WASAPI, VAD, Whisper.NET
  Speak.AI/           — локальные промпты (ONNX/LLM опционально)
  Speak.Hotkeys/      — глобальные хоткеи Win32
  Speak.Clipboard/    — хук буфера обмена
tests/
  Speak.Tests/        — xUnit
```
Команда: `dotnet new wpf -n Speak.App -o src/Speak.App` и т.д.

2.2. Паттерн: **MVVM (CommunityToolkit.Mvvm 8.x, MIT)** — ViewModel на каждый экран из видео: `MainViewModel`, `HotkeysViewModel`, `DictionaryViewModel`, `MeetingNotesViewModel`, `LiveTranslateViewModel`, `ClipboardViewModel`, `SettingsViewModel`.

2.3. Навигация: левый сайдбар = `NavigationView` (WinUI) или свой `ListBox` с 7 пунктами + Settings внизу. Выбранный пункт подсвечивается #1C1C1F.

2.4. Хранение: **SQLite + EF Core 8 (MIT)** или `Microsoft.Data.Sqlite` напрямую. Таблицы: `Dictations(id, timestamp, text, duration, wordCount, audioPath)`, `ClipboardItems(id, timestamp, kind, text, preview)`, `DictionaryWords(word, pronunciation)`, `Hotkeys(id, name, gesture, prompt)`, `Sessions(id, type, startedAt, transcript)`.

2.5. Конфиг: `appsettings.json` + `userSettings.json` в `%APPDATA%\Speak\`.

2.6. Логи: `Serilog` в файл `%APPDATA%\Speak\logs`.

2.7. Автостарт: реестр `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` или Task Scheduler.

2.8. Трей: `Hardcodet.NotifyIcon.Wpf` или нативный `NotifyIcon`.

**Критерий:** `Speak.sln` собирается, окно открывается с сайдбаром и переключает пустые страницы.

## Стадия 4 — Запись аудио и VAD (бесплатно, офлайн)

4.1. Запись: **NAudio 2.2 (MIT)** — WASAPI loopback + микрофон. Класс `WasapiCaptureService` → 16 kHz mono float32, буфер 100 мс.

4.2. VAD (детекция речи): **Silero VAD ONNX (MIT)** через `Microsoft.ML.OnnxRuntime`. Модель 2 МБ — скачивается один раз с HuggingFace (или клади в репо `models/silero_vad.onnx`). Порог 0.5, окно 512 семплов. Альтернатива проще: энергия + zero-crossing (без ML).

4.3. Сегментация: пока VAD = речь → пишем в буфер; тишина > 700 мс → флаш сегмента → отправляем на STT.

4.4. Хоткей старта/стопа: глобальный хук `RegisterHotKey` (Win32) — по умолчанию `CapsLock+Пробел` или `Ctrl+Alt+Space` (настраивается). Удержание = пишет, отпускание = вставляет.

4.5. Индикатор: маленькая плашка 120×32 «Слушаю…» с пульсацией (как в демо 02:00), появляется у каретки или в трее.

4.6. Тест: зажми хоткей → говори 5 сек → отпусти → в логах должен появиться wav-файл `%APPDATA%\Speak\audio\seg_*.wav`.

**Критерий:** запись и VAD работают без интернета.

## Стадия 5 — Распознавание речи STT (оффлайн, бесплатно)

5.1. Движок: **Whisper.NET 1.7+ (MIT)** — биндинг к `whisper.cpp`. Установи пакет: `dotnet add src/Speak.Audio package Whisper.net` + `Whisper.net.Runtime`.

5.2. Модели (все MIT/CC-BY, качай один раз):
- `ggml-tiny.bin` 75 МБ — для теста, быстро.
- `ggml-small.bin` 466 МБ — баланс (рекомендуется).
- `ggml-medium.bin` 1.5 ГБ — максимум качества.
Источник: https://huggingface.co/ggerganov/whisper.cpp → кладёшь в `models/` (не коммить в Git, добавь в `.gitignore`, скачивание скриптом `download-models.ps1`).

5.3. Код:
```csharp
using var whisper = WhisperFactory.FromPath("models/ggml-small.bin");
using var processor = whisper.CreateBuilder().WithLanguage("auto").Build();
using var stream = File.OpenRead(wavPath);
var result = await processor.ProcessAsync(stream);
// result.Text → текст
```

5.4. Язык: auto (ru/en) — как в видео (демка смешанная). Поддержка 99 языков из коробки.

5.5. Потоковость: для «живой» диктовки — чанками по 1 сек, частичный результат.

5.6. Словарь: кастомные слова подмешиваешь как `initial_prompt` — «Словарь: аренда, Ленд Крузер, VSDC…» — улучшает распознавание имён.

5.7. Пост-обработка: капитализация, пунктуация (Whisper уже ставит), тримминг.

5.8. Бенчмарк: small на i5-11300H — ~0.8× realtime (5 сек аудио → 4 сек обработки). На GPU не нужно.

**Критерий:** офлайн-диктовка «Привет, как дела?» → текст появляется в любом поле (Блокнот, Telegram) за ≤2 сек после отпускания хоткея.

## Стадия 6 — Вставка текста и горячие клавиши

6.1. Вставка: `Clipboard.SetText` + `SendKeys.SendWait("^v")` или `SendInput` (Win32) — работает в 99% приложений. Fallback — `UIAutomation` для полей ввода.

6.2. Глобальные хоткеи: класс `GlobalHotkeyService` на `RegisterHotKey`, парсит `Ctrl+Alt+K` и т.д., хранит в SQLite, перерегистрирует при изменении настроек.

6.3. Перехват: при нажатии хоткея → старт записи (4.5), при отпускании → стоп + STT + вставка.

6.4. Режимы (как в видео):
- Диктовка (обычная)
- Режим замены (заменяет выделенный текст)
- Диктовка с ручной правкой (открывает мини-редактор перед вставкой)
Каждый — отдельный хоткей + тоггл в настройках.

6.5. AI-инструкции (см. Стадия 7) тоже на хоткеи: выделить текст → `Ctrl+Alt+F` → «Сделать формально» → заменяет.

**Критерий:** хоткеи работают даже когда окно Speak свёрнуто в трей.

## Стадия 7 — AI-полировка (опционально, но бесплатно и офлайн)

7.1. Простые пресеты без LLM: регулярки — «убрать слова-паразиты», «капитализация», «добавить пунктуацию».

7.2. Локальная LLM (если хочешь как в видео «Профессиональная переработка»):
- Вариант A (рекомендуем): **Phi-3 Mini 3.8B Q4 (MIT)** или **Qwen2.5 0.5B Q4** через `LLamaSharp` (llama.cpp) — ~2 ГБ RAM, работает на CPU.
- Вариант B: `Microsoft.ML.OnnxRuntime` + `onnx` модели.
- Вариант C: внешний **Ollama** (отдельный exe, бесплатно) — Speak просто шлёт HTTP на localhost:11434.

7.3. Промпты (хранятся в `Hotkeys.prompt`):
- «Перевести на английский: {text}»
- «Сделай формально: {text}»
- «Упрости: {text}»

7.4. UI добавления инструкции — модалка из sheet_02 [18]: поля Название, Сочетание клавиш, Инструкция (промпт), чекбоксы.

7.5. Если LLM не установлена — кнопка показывает «Установите Ollama» с ссылкой.

**Критерий:** выделение текста + хоткей → текст заменяется улучшенной версией без интернета.

## Стадия 8 — Остальные фичи из видео (по приоритету)

8.1. **История диктовок (Недавнее):** ListView с виртуализацией, хранит последние N (по умолчанию ∞, настройка «Хранить 1 месяц»). Поиск сверху фильтрует `LIKE %query%`.

8.2. **Словарь:** CRUD слов, хранит в SQLite, подмешивается в `initial_prompt` Whisper и в пост-обработку (замена близких написаний).

8.3. **Заметки о встречах:** запись длительная (микрофон + системный звук WASAPI loopback) → сегментация по 30 сек → STT → саммаризация LLM («Сделай краткое резюме») → сохранение в `Sessions` → UI как в [19] с кнопками Подключить календарь (пока заглушка) / Новая заметка / Import File (выбор wav/mp3).

8.4. **Живой перевод:** два процессора — ru→en, en→ru (можно вторым проходом LLM или отдельной моделью NLLB 600M ONNX). UI как в [20]: выбор источника (Микрофон / Система / Оба), выбор языка, История.

8.5. **Буфер обмена:** `ClipboardHook` через `AddClipboardFormatListener` (Win32) → при `WM_CLIPBOARDUPDATE` читаешь `Clipboard.GetText/GetImage/GetFileDropList` → сохраняешь в SQLite + превью → UI сетка/список с виртуализацией, поиск, лимит 10 000 (настройка), автоудаление старше 30 дней.

8.6. **Настройки хранения:** экран [13] — слайдеры «Хранить диктовки N дней», «Занято места X МБ», кнопка «Очистить», тоггл «Не хранить».

8.7. **Мобильное приложение:** заглушка QR → ссылка на `https://ttklon.github.io/speak` (GitHub Pages бесплатно) с инструкцией.

8.8. **Free-лимит:** счётчик слов `wordsUsed / 800`, хранится локально, при превышении — тост «Лимит исчерпан, очистите историю» (без реального пейволла — ты хотел бесплатно навсегда).

8.9. **Пригласить друзей:** копирует реферальную ссылку `https://github.com/ttklon/speak?ref=xxx`.

**Критерий:** каждая фича из видео имеет соответствующий экран и работает офлайн.

## Стадия 9 — Сборка, инсталлятор и автообновление (бесплатно)

9.1. Публикация: `dotnet publish src/Speak.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true` → один exe ~80 МБ (с рантаймом) или ~25 МБ framework-dependent.

9.2. Инсталлятор: **Inno Setup 6 (бесплатно, MIT)** — скрипт `installer.iss` → `SpeakSetup.exe`. Альтернатива: `Velopack` / `Squirrel.Windows` для автообновлений с GitHub Releases.

9.3. Подпись: для теста — self-signed (`New-SelfSignedCertificate`); для продакшена — бесплатно через `SignPath` или без подписи (Windows покажет SmartScreen — OK для личного использования).

9.4. Автостарт: чекбокс в Настройках → пишет в реестр.

9.5. Иконка: сгенерируй из Speakly логотипа (белый на чёрном, скругление).

9.6. Версионирование: `1.0.0` → `1.0.1` и т.д., тег в Git.

**Критерий:** скачал `SpeakSetup.exe` с GitHub Releases → установил на чистую Windows 11 → приложение запустилось.
