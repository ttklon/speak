# Нужны ли Arena-коннекторы? (коротко: GitHub достаточно)

## Обязательный — GitHub (уже подключен)

- **Что даёт:** Arena читает и пишет в `ttklon/speak`, видит Actions, может создавать PR.
- **Цена:** бесплатно (GitHub Free: ∞ публичных + 2000 мин Actions/мес, приватные репо — 500 МБ пакетов).
- **Как подключить:** Arena → Connectors → GitHub → Authorize → выбрать `ttklon/speak`.

## Опциональные (не нужны для этого проекта, подключай только если хочешь):

| Коннектор | Зачем | Цена | Нужен? |
|---|---|---|---|
| **Slack / Discord** | Уведомления о сборке/релизе | Бесплатно | Нет, можно подписаться на email GitHub Actions |
| **Notion / Google Drive** | Документация / дизайн | Бесплатно | Нет, docs храним в репо |
| **Linear / Jira** | Трекер задач | Бесплатно до N пользователей | Нет, используем GitHub Issues |
| **Figma** | Дизайн макета | Бесплатно (3 проекта) | Полезно, но не обязательно — скрины уже есть |

**Правило:** подключай только GitHub. Каждый лишний коннектор — лишний OAuth и письма.

## Как проверить что GitHub-коннектор работает

- В Arena нажми «Sync» → должен увидеть ветку `arena/c0441a45-speak` и последний коммит.
- Сделай тестовый коммит в Arena → через 30 сек `git fetch` на ПК должен его увидеть.

## Если Arena просит переподключить GitHub

Settings → Connected Apps → GitHub → Disconnect → Connect again → выбери `ttklon/speak`.

---

*Итого: один GitHub-коннектор покрывает 100% задач этого плана.*
