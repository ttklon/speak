# ZSpeakly — лёгкие модели (быстро, не грузят ПК)

## Принцип: только лёгкое, всё офлайн, бесплатно

| Задача | Модель | Размер на диске | RAM пиковая | CPU | Скорость | Качество |
|---|---|---|---|---|---|---|
| Детекция речи | Silero VAD ONNX | 2 МБ | 20 МБ | <1% | 0.01×realtime | 95% |
| Речь→текст (слабый ПК) | Whisper `tiny` ggml-tiny.bin | 75 МБ | 300 МБ | 8–10% | 0.4×realtime (5с аудио→2с) | 85% ru |
| Речь→текст (**рекомендую**) | Whisper `small` ggml-small.bin | 466 МБ | 600 МБ | 12–15% | 0.8×realtime (5с→4с) | 93% ru |
| Речь→текст (тяжёлый, не рекомендуем) | Whisper `medium` | 1.5 ГБ | 1.5 ГБ | 25% | 1.5×realtime | 96% |
| AI-полировка (опционально) | Qwen2.5 0.5B Q4 GGUF | 400 МБ | 500 МБ | 15% | 0.5с/фраза | — |
| AI-полировка альтернатива | Без LLM — правила/регулярки | 0 МБ | 0 МБ | 0% | мгновенно | 70% |

**Итого минимум:** 77 МБ (VAD+tiny), **рекомендуемый комплект:** 468 МБ (VAD+small) — помещается на любом ноутбуке. Никаких 7B LLM по 4 ГБ.

## Что скачивать

Одна команда (по выбору):

```powershell
# Только рекомендуемое (468 МБ):
powershell -ExecutionPolicy Bypass -File C:\dev\speak\scripts\download-models.ps1

# Вручную tiny для теста:
Invoke-WebRequest -Uri https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-tiny.bin -OutFile models/ggml-tiny.bin
```

## Настройка в приложении

Настройки → Голосовая диктовка → Модель: `tiny` (ноутбук) / `small` (ПК) → Сохранить. Переключение без перезапуска.

Если ПК <8 ГБ RAM — ставь `tiny` + отключи AI-полировку (чекбокс в Настройках).

## Почему быстро

- Whisper.NET использует `whisper.cpp` на C++ с AVX2/AVX-512, без Python.
- Квантование Q4 для LLM — 4 бита/вес, без потери смысла для коротких фраз.
- VAD отбрасывает тишину — не гоняет STT впустую.

Замеры на i5-11320H (ноутбук 2021): tiny 1.8 сек на 5 сек речи, small 3.9 сек. На Ryzen 5 5600: small 2.1 сек.
